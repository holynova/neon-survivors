# NEON SURVIVORS — 3D 类幸存者 Roguelite
**Design Document v1.0**

---

## 1. 一句话定位

> 一款跑在浏览器里的 3D 俯视角「类幸存者」自动战斗 Roguelite。
> 你是被困在霓虹竞技场中的最后一名猎手，武器自动开火，你只负责走位、抉择与成长。

对标 **Brotato（ potato brothers / 幸存者模式）× Vampire Survivors × Hi-Fi Rush 的打击感**。

---

## 2. 核心体验支柱（Pillars）

| 支柱 | 含义 | 设计落点 |
|---|---|---|
| **P1 走位即操作** | 玩家 100% 的输入只有移动 | 自动攻击；深度来自空间管理（聚怪、清场、绕后、拉开距离） |
| **P2 差异化武器** | 每把武器 = 一种独立玩法，而非数值变体 | 8 把武器，覆盖锥形散射、贯穿直线、抛物 AoE、链式弹跳、环绕、持续场、追踪、榴弹 |
| **P3 差异���角色** | 角色改变构筑规则，而非只改数值 | 5 个角色，各自改写移动/暴击/掉落/召唤/治疗规则 |
| **P4 打击感至上** | 每次命中都必须"有声音、有粒子、有形变" | 命中闪白、击退、伤害数字、粒子爆裂、屏幕震动、Hitstop |
| **P5 构建构筑** | 每局 20 分钟内长出独特 Build | 三选一升级卡（含武器/被动/角色专属）、稀有度、进化配方、商店 |

## 3. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 渲染 | **Three.js r186**（WebGL2） | 3D 场景 + 自定义 Shader 粒子 + 后期处理成熟；生态最稳 |
| 构建 | **Vite 8** | 秒级 HMR，产物为静态文件，可直接 `dist/` 交付 |
| 语言 | 原生 ES Modules JavaScript | 零框架开销，逻辑层可被 Node 直接单测 |
| 物理 | 自研轻量 2D 圆形碰撞（XZ 平面） | 幸存者类只需圆形重叠检测；自研可完全单测 |
| 粒子 | **自研 GPU-friendly Points 粒子池**（CPU 模拟 + Shader 渲染） | 单一 `BufferGeometry` 承载 20k+ 粒子，属性一次上传 |
| 后期 | **自定义 Bloom / 色差 / 暗角 / 扫描线 Pass** | 单 Pass 全屏合成，避免多 Pass 开销 |
| 音频 | **Web Audio 程序化合成** | 零资源文件，射击/命中/升级全部用振荡器+噪声合成 |
| 测试 | **node:test**（纯逻辑）+ **Playwright**（e2e + 截图） | 每阶段回归 |

### 渲染架构
```
Scene
├─ Arena        无限网格地面 + 霓虹边墙 + 网格辉光（自定义 Shader）
├─ Entities     InstancedMesh / 单 Mesh 池：玩家、敌人、投射物、宝箱
├─ FX
│  ├─ ParticleSystem (Points ×4 池: spark / smoke / shard / glow)
│  ├─ Trails       (拉伸带状 Mesh)
│  ├─ Shockwaves   (地面圆环 Expanding)
│  ├─ Decals       (地面灼烧 / 冰冻 / 电弧 贴片)
│  └─ Beams        (闪电 / 激光 加法混合四边形)
├─ Lights       半球光 + 玩家点光 + 每武器一盏动态点光（有限预算）
└─ PostFX       Bloom + ChromaticAberration + Vignette + Grain + 受伤红闪
```

## 4. 玩法循环

```
选角色 ──► 进入竞技场 ──► [战斗 60~90s 一波]
                │              │
                │              ├─ 击杀掉落经验宝珠 / 治疗包 / 金币
                │              ├─ 经验满 → 三选一升级卡（暂停）
                │              └─ 波次结束 → 商店（买武器/回血/Buff）
                │              │
                └──────────────┴─► 波次递增：敌人数量↑ 数值↑ 新类型解锁
                                     每 5 波 → BOSS 波
  死亡 → 结算面板（本局统计 + Build 回顾）→ 重开（换角色）
```

* 单局时长目标：**12~20 分钟**
* 波次时长：**60s**（BOSS 波 75s）
* 全程共 **20 波**，第 20 波为终局 BOSS「虚空吞噬者」

## 5. 操作

| 输入 | 行为 |
|---|---|
| `WASD` / 方向键 | 移动（8 向，模拟量输入，带惯性） |
| `Shift`（按住） | 冲刺（消耗体力，有冷却、拖尾残影） |
| `E` | 手动释放角色技能 |
| `空格` | 暂停 / 继续 |
| `1/2/3` | 升级卡快速选择 |
| `Q` | 使用恢复类道具 |
| 鼠标 | 菜单点击 |

## 6. 角色设计（5 个，玩法规则不同）

| 角色 | 基础武器 | 角色规则（Passive） | 主动技能（E） | 玩法定位 |
|---|---|---|---|---|
| **猎人 Vanguard** | 霰弹枪 Scatter | 移速 +12%；击杀有 15% 概率额外掉落金币 | **过载冲锋**：3s 内移速 +80%、攻速 +60% | 均衡、易上手 |
| **工程师 Engineer** | 脉冲机枪 SMG | 每 5 次击杀召唤 1 架无人机（自动索敌） | **部署信标**：原地部署治疗信标 6s | 铺场、build 自动化 |
| **爆破手 Demolitionist** | 榴弹发射器 | 爆炸半径 +35%；爆炸击杀额外 +30% 经验 | **集束装药**：向瞄准方向发射 5 连发集束炸弹 | 清群爆发 |
| **电刑者 Arcwelder** | 特斯拉线圈 Tesla | 弹跳次数 +2；命中减速敌人 | **电网过载**：全场敌人感电 2.5s（持续伤害+麻痹） | 控场连锁 |
| **霜蚀者 Cryomancer** | 霜冻喷枪 Frost | 命中使敌人减速 45%，自身留下冰霜轨迹（敌人减速） | **绝对零度**：半径 12 范围冻结敌人 3s | 风筝、控场 |

> 角色差异不是数值：分别改写 **掉落 / 召唤 / 范围 / 连锁 / 减速** 五套规则。

## 7. 武器设计（8 把，行为互不重复）

| # | 武器 | 攻击形态 | 关键机制 | 手感/特效 |
|---|---|---|---|---|
| 1 | **霰弹枪 Scatter** | 每次 5~9 发锥形弹丸，短射程 | 每发独立散布，近距离全中 = 高爆发 | 枪口闪光 + 锥形弹道 + 命中火花 |
| 2 | **脉冲机枪 SMG** | 高射速单体弹 | 射速随机抖动；连续射击时射速缓升 | 曳光弹 + 枪口余焰 + 弹壳抛出 |
| 3 | **特斯拉线圈 Tesla** | 命中即弹跳 | 弹跳至多 4 次，伤害衰减 12%/次 | 锯齿闪电折线 + 电弧环 + 麻痹火花 |
| 4 | **榴弹发射器 Grenade** | 抛物线弹丸 + AoE | 落地引信 0.45s，范围爆炸，带冲击波 | 抛物旋转体 + 抛物拖尾 + 地面冲击环 + 抛射碎片 |
| 5 | **霜冻喷枪 Frost** | 持续锥形粒子流 | 持续 DPS，命中附加减速与霜冻 | 冷雾粒子 + 地面冰霜贴片 + 冰晶闪光 |
| 6 | **轨道护卫 Orbital** | 2~4 颗环绕轨道体 | 接触伤害 + 击退，攻速由转速决定 | 螺旋轨迹 + 残影拖尾 + 击中时白色冲击星 |
| 7 | **狙击重炮 Railgun** | 长直线高速弹，穿透一切 | 充能 0.9s，发射贯穿光矛，命中后小范围爆炸 | 屏幕震动 + 光矛拉伸 + 冲击白闪 + 慢镜 0.08s |
| 8 | **蜂群飞弹 Swarm** | 自动锁定追踪弹 | 最多 6 发在空，分散锁定最近敌人 | 尾迹 + 加速曲线 + 命中分裂小爆 |

**武器槽位**：初始 2 个，最多 6 个。
**武器等级**：1~4 级（升级卡），4 级后可通过配方 **进化**（如 `SMG4 + 电磁核心` → **脉冲加特林 Arclight**）。
**武器协同（Synergy）**：同时持有 3 把「元素类」武器 → 触发被动元素共鸣（燃烧/冰霜/感电叠加）。

| 敌人 | 行为 | 特征 |

| **Splitter 分裂体** | 死亡分裂成 2 个小体 | 高数量压制 |
| **BOSS: 熔核 Colossus** | 环形弹幕 + 冲锋 | 第 5 波 |

## 9. 成长系统

### 经验与等级
* 宝珠磁吸半径随等级增长（2.2 → 5.5）
* 升级所需经验：`need(l) = 5 + l*4 + l^1.55*1.6`
* 每级三选一卡，卡池权重受稀有度与当前 Build 影响

### 卡池分类
| 类别 | 例子 | 稀有度 |
|---|---|---|
| 新武器 | 「获得：轨道护卫」 | 稀有 |
| 武器升级 | 「霰弹枪 Lv3：+1 弹丸」 | 普通/稀有 |
| 进化 | 「进化：霜冻喷枪 → 绝对零域」 | 传说 |
| 通用被动 | 移速 +8%、最大生命 +20、拾取范围 +25%、冷却 -10% | 普通 |
| 元素被动 | 燃烧/冰霜/感电 伤害 +25% | 稀有 |
| 角色专属 | 仅该角色出现（Vanguard 额外掉落 / Arcwelder 弹跳 +1） | 稀有 |
| 补给 | 治疗 30%、金币 +40 | 普通 |

### 稀有度
`common → rare → epic → legendary`，卡面边框颜色/粒子/音效不同。

## 10. 经济与商店
* 击杀掉落金币（10~40），宝珠掉落经验（1~5）
* 商店在每波结束开放，卖 4 件随机商品 + 「修复」（回 40% 生命）
* 价格随波次轻微上涨，避免无脑囤积

## 11. FX 规格（"酷炫" 的工程定义）

> 硬性指标：单帧粒子不超过 **20000**，任意时刻活跃 FX 实例 < **300**，目标 **60fps @ 1080p**（集显 ≥ 45fps）。

| 特效 | 实现 |
|---|---|
| 命中火花 | 12~20 个 `spark` 粒子，方向 = 击退方向，初速锥形分布，寿命 0.25s，颜色继承伤害类型 |
| 死亡爆裂 | 环形排布 24 个 `shard` + 一圈 `glow` 闪片 + 一片 `smoke` |
| 枪口闪光 | 十字星形加法四边形 + 点光脉冲 0.06s |
| 曳光弹 | 拉伸四边形 trail，长度 = 速度 × 0.03 |
| 冲击波 | 地面加法圆环，0.35s 扩张 + 淡出，附带 12 根放射状线条 |
| 闪电 | 每帧重算折线（8 段），加法混合 `glow` 粒子沿线分布 |
| 屏幕震动 | trauma 值模型（`shake = trauma²`），trauma 随事件累加并衰减 |
| Hitstop | 重装/爆炸命中时全局时间缩放 0.35 持续 0.045s |
| 慢镜 | Railgun 击杀时 timeScale 0.25 持续 0.12s |
| 死亡回放 | 精英/ Boss 死亡：时间缩放 0.2 + 径向白闪 + 12 颗慢速子弹时间弹片 |
| 升级 | 屏幕径向光扫 + 8 道几何光柱 + 中心环形冲击波 |
| Bloom | 自定义亮度提取 + 双通道高斯模糊 + 加法合成，阈值 0.62，强度 1.35 |

## 12. 音频设计（程序化，无外部资源）

| 事件 | 合成方式 |
|---|---|
| 射击 | 白噪声 burst + 锯齿波下滑，包络 0.08s，按武器类型调基频 |
| 命中 | 短方波 pop，音高随伤害 |
| 爆炸 | 低频正弦下滑 120→30Hz + 噪声尾 |
| 闪电 | 高通噪声 + 随机门限，模拟电弧 |
| 升级 | 大三和弦琶音（C-E-G-C） |
| 受击 | 低频方波 + 失真 |
| BOSS 出现 | 下滑低鸣 + 反向噪声 |

## 13. 技术模块划分

```
src/
  core/
    math.js        向量/角度/随机 纯函数
    rng.js         可复现 PRNG (mulberry32)
    input.js       键鼠输入 → 语义动作
    loop.js        固定步长主循环 + timeScale/hitstop
    audio.js       Web Audio 程序化合成
    pool.js        通用对象池
  game/
    config.js      全部数值配置（集中可调）
    entities.js    实体数据模型
    collision.js   圆形碰撞（纯函数，可单测）
    player.js      移动/冲刺/无敌帧/属性
    stats.js       属性聚合 + 派生（攻速/伤害/范围…）
    weapons.js     8 把武器定义 + 开火逻辑
    projectiles.js 投射物池 + 追踪/弹跳/爆炸
    enemies.js     敌人定义 + AI 状态机
    spawner.js     波次生成 + BOSS
    pickups.js     宝珠/金币/治疗 磁吸
    upgrades.js    卡池 + 稀有度 + 进化配方
    shop.js        商店
    game.js        世界组装 / 胜负流程
  fx/
    particles.js   通用粒子系统（Points + Shader）
    trails.js      拖尾带
    shockwave.js   冲击环
    beams.js       闪电/激光
    decals.js      地面贴片
    postfx.js      Bloom 等全屏后期
    juice.js       屏幕震动 / hitstop / 慢镜 / 白闪
    floaters.js    伤害数字
  ui/
    hud.js         血条/经验/计时/波次
    cards.js       升级三选一
    menus.js       主菜单/角色选择/结算
    style.css
  main.js          引导
```

**纯逻辑原则**：`collision / math / rng / stats / upgrades / spawner / weapons(数据部分)` 全部不依赖 Three.js，可被 node:test 直接测试。

## 14. 验收标准

* [ ] 启动无报错，控制台无 error
* [ ] 8 把武器全部可装备、行为互异、有独立特效
* [ ] 5 个角色机制生效且手感不同
* [ ] 8 种敌人 + 3 个 BOSS 行为可辨识
* [ ] 升级卡池/进化/商店/结算/重开全流程闭环
* [ ] 峰值 60fps @ 1080p（集显 45+）
* [ ] 单元测试 100% 通过
* [ ] e2e：加载 → 移动 → 击杀 → 升级 → 商店 → 死亡结算 全部通过
* [ ] `npm run build` 产物可直接静态托管
